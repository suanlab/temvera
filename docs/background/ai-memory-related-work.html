T1메모리 생애주기 벤치마크 — 존재기반 회수를 넘어
벤치마크★ Temvera

회수율이 아니라 쓰기·통합·망각·모순해소 연산 자체를 채점. 유효기간을 가진 다세션 히스토리를 절차적 생성, 반사실적 갱신·시간유효 질의를 LLM-judge 없이 정답 계산. FAMA식 망각 페널티 + judge-free 정확 지표 동시 보고.

가장 근접한 선행연구

  • From Recall to Forgetting (Memora / FAMA) · ACL 2026 Findings (채택) — FAMA 지표로 폐기·무효 메모리 의존을 벌점. 2604.20006. 단, 채점이 human+auto 하이브리드이고 QA 중심.
  • MemStrata — Temporal Validity in Retrieval Memory · preprint — 결정론적 supersession + 마커 없는 계산가능 정답(LLM 무호출). 2606.26511. judge-free 요구에 가장 근접하나 자기 방법 검증용으로 협소.
  • MemoryAgentBench · preprint — 정확회수·test-time학습·장기이해·선택적 망각 4역량. 2507.05257. 망각을 LLM judge로 채점.
  • GEM — Is Agent Memory a Database? · preprint — 4개 상태연산자(수집·개정·망각·회수)+6 정확성조건. 2605.26252. 연산 어휘는 제공하나 벤치는 없음.
  • MemConflict / STALE / EvoMemBench — 모순 분류·시간유효 질의 설계. 2605.20926 · 2605.06527 · 2605.18421

정확한 미해결 갭

다음 전부를 결합한 벤치마크가 없음: ① 유효기간 명시 히스토리의 절차적 생성, ② write/merge/expiry/contradiction을 분리 이벤트로 직접 채점, ③ LLM-judge 없는 계산가능 정답, ④ FAMA 페널티와 judge-free 지표 동시 보고. 개별 조각(망각 지표·모순 분류·결정론적 supersession)은 이미 혼잡하나 통합된 생성기 기반 연산수준 스위트는 미구축.

베이스라인/데이터셋: Mem0·MemGPT/Letta·LangMem·A-MEM·raw long-context·vanilla RAG // LOCOMO·LongMemEval(-V2)·MemoryAgentBench·MemConflict·STALE·MemStrata. judge-vs-계산정답 일치를 human-agreement 슬라이스로 검증.

◑ 조합상 열림 조각들은 혼잡하나, 절차생성·유효기간·완전 judge-free·연산수준 조합은 미존재.
T2메모리 judge 메타평가 하네스
평가 인프라

LLM-judge의 신뢰성 및 타당성을 메모리 과업(시간추론·모순·망각)에 특화 측정: 온도민감도·편향·인간일치 신뢰구간. 모든 후속 메모리 논문이 점수와 함께 judge 품질을 보고하게 만드는 인프라.

가장 근접한 선행연구

  • Reliability without Validity · preprint — 21모델·541k 판정, κ/α·test-retest·위치/장황편향. 2606.19544. MT-Bench/JudgeBench/RewardBench — 메모리·시간·모순 과업 없음.
  • Judge Reliability Harness (RAND) · preprint — 라벨플립·패러프레이즈 불변·장황편향·안정성 하네스. 2603.05399. fork할 방법 템플릿이나 벤치는 안전/설득 — 메모리 아님.
  • AgentProp-Bench · preprint — 에이전트 judge 신뢰성·오류전파 캐스케이드. 2604.16706
  • Policy Invariance as Reliability Test · preprint — 불변성 기반 신뢰성(유효기간 스왑에 판정 불변 등 이전 가능). 2605.06161

정확한 미해결 갭

모든 기존 하네스는 판정 대상을 정적 선호/정답으로 취급. 메모리 judging 고유 실패면 — ① 시간유효성 추론(질의 시점에 유효했나), ② "올바르게 망각/만료" vs "회수 실패" 구분, ③ superseded↔current 모순 해소 — 을 격리한 것이 없음. 메모리 특화 섭동(유효기간 스왑·superseded distractor 주입·세션 재정렬)과 sub-skill별 human-agreement CI가 미제공.

베이스라인: GPT/Claude/Llama/Qwen judge + fine-tuned reward judge // JRH + 2606.19544 지표(κ·α·test-retest). 과업 기질: LongMemEval 시간추론·knowledge-update, MemConflict, STALE, 그리고 T1 judge-free 스위트(judge-vs-계산정답 CI 산출).

● 열림 범용 judge 메타평가는 혼잡, 메모리 특화(시간/모순/망각)+human-agreement CI 하네스는 미구축.
T3리랭커 조건부 융합 — 강한 cross-encoder가 있으면 학습 융합은 잉여인가?
실증연구

리랭커를 고정한 채, 학습/적응 융합 가중이 RRF+rerank 대비 통계적으로 유의한 한계 이득을 주는지 BEIR+에이전트메모리에서 검증. 명료한 결정적(negative-or-positive) 결과.

가장 근접한 선행연구

  • Reciprocal Rank Fusion · SIGIR 2009 (동료심사) — 순위기반 융합, 고정 베이스라인. RRF
  • vstash — Adaptive Fusion · preprint — IDF 적응 RRF, BEIR 5셋 +0.1~21.4% NDCG. 2604.15484. 단 리랭커 없는 검색 단계 — 정확히 이 연구가 제거하는 교란.
  • From BM25 to Corrective RAG · preprint — 융합이 상류 recall은 올리나 cross-encoder 리랭킹+top-K 후엔 동등/열위. 2604.01733. 가장 근접한 힌트, 그러나 학습융합-vs-RRF 대조 아님·유의성 검정 없음.
  • HYRR · preprint — 리랭커를 하이브리드 후보로 학습(융합을 리랭커에 얽음, 반대 설계). 2212.10528

정확한 미해결 갭

특정 통제 실험이 문헌에 없음: 강한 cross-encoder 하나를 고정하고, 학습/적응 융합이 순수 RRF+rerank 대비 유의한 한계 이득을 주는지 — 리랭커 불변 조건에서, BEIR 및 에이전트메모리(방해요소가 superseded/stale 사실) 양쪽에서. 기존 근거는 (a) 리랭커 없이 학습융합 승리(vstash), (b) 일화적으로 리랭킹이 융합 이득 소거 — 둘 다 통제 대조가 아님.

베이스라인: dense+rerank, BM25+rerank, RRF+rerank, 학습융합+rerank, ColBERT+rerank(강한 1단계 대조). 고정 리랭커 bge-reranker-v2/MonoT5-3B/Cohere. // BEIR + TREC-DL19/20 + LOCOMO/LongMemEval/MemConflict 검색 서브셋. paired bootstrap 유의성 검정.

● 열림(협소) 하이브리드+리랭킹은 혼잡하나, 리랭커 고정 한계효용 ablation은 미보고 — 방어가능한 negative-result 기여.

정확한 미해결 갭

망각을 형식 보증을 가진 인덱스 1급 연산으로 만든 것이 없음: (a) 시간감쇠 엣지가중/TTL 회수를 네이티브 그래프 연산자로(기존은 전부 tombstone+컴팩션, 감쇠는 앱 계층), (b) upsert+forget 스트림 하 증명가능 Δrecall 한계(2607.00728이 최근접이나 휴리스틱), (c) 감쇠 결합 hot/cold 티어링. 이 교집합은 미해결.

베이스라인: SPFresh·FreshDiskANN·UBIS·DGAI·2607.00728 + tombstone-HNSW/Vamana. // Big-ANN NeurIPS'23 streaming track(4:4:1), CANDOR-Bench, SIFT1B/Deep1B/MS-Turing + 직접 구축 TTL/decay 스트림(표준 부재 = 기여).

● 열림 갱신/처닝은 혼잡, 네이티브 감쇠+증명 드리프트 한계+망각주도 티어링은 무선행.
T5살리언스·충돌 인식 에이전트 메모리 검색
알고리즘★ Temvera

검색 점수를 의미유사도 + 최근성 + 쓰기 프로비넌스 + 모순신호로 구성. 충돌 메모리를 생성 하류가 아니라 검색 시점 리랭킹/기권 문제로 취급.

  • Zep / Graphiti · preprint — bitemporal 유효성 + 하이브리드+리랭킹. 2501.13956. 모순을 검색 시점 신호로 미모델·기권 미지원.
  • TOKI · preprint — bitemporal 모순해소 대수. 2606.06240. 저장/통합 계층이지 질의시 리랭킹 아님.
  • Don't Ask the LLM to Track Freshness · preprint — 결정론적 freshness 레시피, "생성에 위임 말라"는 논지 일치. 2606.01435
  • SPAR — Salient Phrase Aware Dense Retrieval · EMNLP 2022 (동료심사) — 살리언스 증강 dense 검색 기반. PDF

정확한 미해결 갭

의미유사도 + (a)최근성 + (b)쓰기 프로비넌스 + (c)후보 간 명시적 모순 신호를 단일 학습 스코어링으로 융합하고, 검출된 충돌을 검색 시점 리랭킹/기권으로 처리하는 검색기가 없음. 기존은 (i)모순검출 없는 최근성 랭킹, (ii)저장/통합 시점 결정론 해소, (iii)충돌 평가만 — 셋으로 분리. 후보 간 모순을 채점하고 생성 전 기권할 수 있는 학습 리랭커가 빈 셀.

베이스라인: dense top-k(BGE/E5/Contriever)·BM25+dense RRF·cross-encoder·Zep 하이브리드·Mem0 decay 리랭킹·Self-RAG. // MemConflict·MemoryAgentBench(FactConsolidation/EventQA)·BEAM·LongMemEval·LoCoMo.

● 열림 인접 연구는 최근성 랭킹/저장시 해소/충돌 평가 중 하나만 — 프로비넌스·최근성 융합 + 기권형 검색 리랭커는 미착수.

T8bitemporal MVCC 트랜잭션 메모리 저장소

(event-time, ingestion-time) 키의 다버전 동시성제어·스냅샷 격리 읽기·동시 다중에이전트 쓰기의 형식적 직렬성 정확성 모델(모순해소를 직렬화 연산으로).

가장 근접한 선행연구

  • Zep / Graphiti · preprint — bitemporal 엣지(event+ingestion). 2501.13956. MVCC·격리수준·동시성 보증 없음.
  • TOKI — Bitemporal Operator Algebra · preprint (cs.DB) — 4 해소 휴리스틱을 bitemporal 연산자로 타이핑, 연산별 격리 전제+감사행. 2606.06240. 쓰기연산 대수이지 스냅샷격리 읽기·다중작성자 직렬성 증명 아님.
  • Fast Serializable MVCC (HyPer) · SIGMOD 2015 (동료심사) — precision-locking 검증. PDF. 단일시간(transaction-time)·모순 개념 없음.
  • Serializable Snapshot Isolation · SIGMOD 2008 (동료심사) — SI+의존추적 직렬성. bitemporal 에이전트 메모리에 미적용.
  • SQL:2011 system/application-time · Snodgrass TSQL2 — (valid,transaction) 표준 = (event,ingestion). LLM 모순/직렬성 계층 없음.

정확한 미해결 갭

세 가지를 결합한 DB급 트랜잭션 모델이 없음: (a) (event,ingestion) 키 MVCC + 버전가시성 규칙 + 스냅샷 격리/타임트래블 읽기(Graphiti는 저장만·격리 없음), (b) 동시 다중에이전트 쓰기의 직렬성 정확성 모델(TOKI는 연산별 전제만·전체 스케줄 정리 없음), (c) 모순해소를 그 동시성이론에 통합된 직렬화 연산으로. 고전 MVCC/SSI와 bitemporal 에이전트 메모리 휴리스틱이 별개 문헌으로 남아 미통합.

베이스라인: Zep/Graphiti·TOKI 4연산자·mem0/MemGPT·고전 직렬 MVCC(HyPer/SSI 천장). // LoCoMo·DMR 검색품질 + 모순주입 동시쓰기 워크로드(격리 이상률·직렬성 위반 측정) + 시간 QA(as-of/타임트래블). 표준 부재 = 기여.

● 열림 bitemporal 저장·모순 휴리스틱·고전 MVCC/SSI는 각각 존재, 증명된 다중에이전트 직렬성 bitemporal-MVCC 저장소는 미구축.
