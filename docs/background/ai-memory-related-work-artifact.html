T1메모리 생애주기 벤치마크 — 존재기반 회수를 넘어
벤치마크★ Temvera

회수율이 아니라 쓰기·통합·망각·모순해소 연산 자체를 채점. 유효기간을 가진 다세션 히스토리를 절차적 생성, 반사실적 갱신·시간유효 질의를 LLM-judge 없이 정답 계산.

가장 근접한 선행연구

  • From Recall to Forgetting (Memora / FAMA) · ACL 2026 Findings (채택) — FAMA 지표로 폐기·무효 메모리 의존을 벌점. 2604.20006. 단, 채점이 human+auto 하이브리드·QA 중심.
  • MemStrata · preprint — 결정론적 supersession + 마커 없는 계산가능 정답(LLM 무호출). 2606.26511. judge-free 요구에 최근접하나 자기 방법 검증용으로 협소.
  • MemoryAgentBench · preprint — 정확회수·test-time학습·장기이해·선택적 망각 4역량. 2507.05257. 망각을 LLM judge로 채점.
  • GEM — Is Agent Memory a Database? · preprint — 4개 상태연산자+6 정확성조건. 2605.26252. 연산 어휘는 제공하나 벤치는 없음.
  • MemConflict / STALE / EvoMemBench — 모순 분류·시간유효 질의 설계. 2605.20926 · 2605.06527 · 2605.18421

정확한 미해결 갭

다음 전부를 결합한 벤치마크가 없음: ① 유효기간 명시 히스토리의 절차적 생성, ② write/merge/expiry/contradiction을 분리 이벤트로 직접 채점, ③ LLM-judge 없는 계산가능 정답, ④ FAMA 페널티와 judge-free 지표 동시 보고. 개별 조각은 혼잡하나 통합 생성기 기반 연산수준 스위트는 미구축.

베이스라인/데이터셋: Mem0·MemGPT/Letta·LangMem·A-MEM·raw long-context·vanilla RAG // LOCOMO·LongMemEval(-V2)·MemoryAgentBench·MemConflict·STALE·MemStrata.

◑ 조합상 열림 조각들은 혼잡하나, 절차생성·유효기간·완전 judge-free·연산수준 조합은 미존재.

가장 근접한 선행연구

  • Judge Reliability Harness (RAND) · preprint — 라벨플립·불변·안정성 하네스. 2603.05399. 벤치는 안전/설득 — 메모리 아님.
  • AgentProp-Bench · preprint — 에이전트 judge 신뢰성·오류전파. 2604.16706
  • Policy Invariance as Reliability Test · preprint — 불변성 기반 신뢰성. 2605.06161

정확한 미해결 갭

모든 기존 하네스는 판정 대상을 정적 선호/정답으로 취급. 메모리 judging 고유 실패면 — 시간유효성 추론, "망각/만료 vs 회수실패" 구분, superseded↔current 모순 해소 — 을 격리한 것이 없음. 메모리 특화 섭동과 sub-skill별 human-agreement CI가 미제공.

과업 기질: LongMemEval 시간추론·knowledge-update, MemConflict, STALE, 그리고 T1 judge-free 스위트(judge-vs-계산정답 CI 산출).

● 열림 범용 judge 메타평가는 혼잡, 메모리 특화+human-agreement CI 하네스는 미구축.
T3리랭커 조건부 융합 — 강한 cross-encoder가 있으면 학습 융합은 잉여인가?
실증연구

리랭커를 고정한 채, 학습/적응 융합 가중이 RRF+rerank 대비 통계적으로 유의한 한계 이득을 주는지 BEIR+에이전트메모리에서 검증.

가장 근접한 선행연구

  • Reciprocal Rank Fusion · SIGIR 2009 (동료심사) — 순위기반 융합, 고정 베이스라인. RRF
  • vstash — Adaptive Fusion · preprint — IDF 적응 RRF, BEIR +0.1~21.4% NDCG. 2604.15484. 단 리랭커 없는 검색 단계 — 이 연구가 제거하는 교란.
  • From BM25 to Corrective RAG · preprint — 융합이 상류 recall은 올리나 리랭킹 후엔 동등/열위. 2604.01733. 가장 근접한 힌트, 유의성 검정 없음.
  • HYRR · preprint — 리랭커를 하이브리드 후보로 학습(반대 설계). 2212.10528

정확한 미해결 갭

강한 cross-encoder 하나를 고정하고 학습/적응 융합이 순수 RRF+rerank 대비 유의한 한계 이득을 주는지 — 리랭커 불변 조건에서 BEIR 및 에이전트메모리(방해요소=superseded/stale) 양쪽에서 — 검증한 통제 실험이 문헌에 없음.

베이스라인: dense/BM25/RRF/학습융합/ColBERT ×rerank(bge-reranker-v2 등 고정) // BEIR + TREC-DL + LOCOMO/LongMemEval/MemConflict. paired bootstrap 유의성 검정.

● 열림(협소) 하이브리드+리랭킹은 혼잡하나, 리랭커 고정 한계효용 ablation은 미보고 — 방어가능한 negative-result 기여.

정확한 미해결 갭

망각을 형식 보증을 가진 인덱스 1급 연산으로 만든 것이 없음: 네이티브 감쇠/TTL 연산자 + upsert/forget 스트림 하 증명가능 Δrecall 한계 + 감쇠 결합 hot/cold 티어링의 교집합은 미해결.

베이스라인/벤치: SPFresh·FreshDiskANN·UBIS·DGAI // Big-ANN streaming track·CANDOR-Bench·SIFT1B/Deep1B + 직접 구축 TTL/decay 스트림(표준 부재=기여).

● 열림 갱신/처닝은 혼잡, 네이티브 감쇠+증명 드리프트 한계+망각주도 티어링은 무선행.
T5살리언스·충돌 인식 에이전트 메모리 검색

가장 근접한 선행연구

  • MemConflict · preprint — 현재 질의에 유효한 항목 랭킹이 핵심. 2605.20926. 평가 벤치이지 스코어러 제안 아님.
  • Zep / Graphiti · preprint — bitemporal 유효성 + 하이브리드+리랭킹. 2501.13956. 모순을 검색 시점 신호로 미모델·기권 없음.
  • TOKI · preprint — bitemporal 모순해소 대수. 2606.06240. 저장/통합 계층이지 질의시 리랭킹 아님.
  • SPAR · EMNLP 2022 (동료심사) — 살리언스 증강 dense 검색 기반. PDF

정확한 미해결 갭

의미유사도 + 최근성 + 프로비넌스 + 후보 간 명시적 모순 신호를 단일 학습 스코어링으로 융합하고, 충돌을 검색 시점 리랭킹/기권으로 처리하는 검색기가 없음. 기존은 최근성 랭킹 / 저장시 해소 / 충돌 평가로 분리.

베이스라인/벤치: dense(BGE/E5)·RRF·cross-encoder·Zep·Mem0 decay·Self-RAG // MemConflict·MemoryAgentBench·BEAM·LongMemEval·LoCoMo.

● 열림 프로비넌스·최근성 융합 + 기권형 검색 리랭커는 미착수.
