# 논문 제안서 — T1: 메모리 생애주기 벤치마크

> **작업 제목:** *Beyond Presence: A Procedurally-Generated, Judge-Free Benchmark for Memory Lifecycle Operations*
> 유형: 벤치마크 / 평가 인프라 · 위험도: 낮음 · 실현가능성: 높음
> 작성일 2026-07-15 · 근거: [선행연구 조사](./ai-memory-related-work.html) T1 · **[통합 프로그램 계획](./research-program.md)**

> ⚠️ **선행연구 갱신(2026-07 충돌조사 반영) — "최초 망각벤치" 주장 폐기:** 직접 경쟁자 **deeplethe/lethe의 ForgetEval**(supersession·decay·amnesia·purge·drift 5범주 망각 벤치마크, "잊도록 만든 AI 메모리")가 존재한다. → 원 제안의 "최초 생애주기/망각 벤치" 프레이밍은 **선점**됨.
> - **재정의된 범위:** ForgetEval이 이미 절차생성·judge-free 5범주를 제공함을 고정 소스에서 확인했다. Mem2ActBench도 dynamic memory evolution과 tool use를 평가한다. 남은 측정 차이는 exact bitemporal `as-of` state, operation trace, rebuild/purge completeness, provenance-action trace이다.
> - 어떤 "최초" 주장도 체계적 검토와 외부 재현 완료 전 사용하지 않는다.

---

## 1. 초록 (Pitch)

많은 에이전트 메모리 벤치마크가 회수를 중심으로 하지만 LongMemEval은 갱신·기권을, ForgetEval은 lifecycle을, Mem2ActBench는 memory evolution과 tool use를 이미 다룬다. 남은 문제는 동일한 상태 궤적에서 개별 연산과 두 시간축의 정답을 직접 검사하는 것이다. 우리는 **쓰기·통합·망각·모순해소 연산을 분리 채점**하고, 명시적 validity window와 transaction time을 가진 히스토리에서 `as-of` 정답을 LLM 호출 없이 계산한다. 산출물은 생성기·데이터셋·재현 하네스이며, 신규성은 비교 재현 전 가설로 둔다.

---

## 2. 문제 정의 & 동기

**측정이 방향을 정한다.** 존재 기반 정확도는 폐기됐어야 할 메모리 사용을 벌하지 않아 장기 성능을 **과대평가**한다(Memora/FAMA, ACL 2026 Findings). GEM(arXiv 2605.26252)은 메모리 정확성이 상태 궤적에 달렸고 표준 CRUD로는 포착 안 됨을 논증하며 4개 상태연산자(수집·개정·망각·회수)를 제안했으나 — **벤치마크를 내놓지는 않았다.**

**judge 문제.** 대다수 메모리 점수는 LLM-judge 기반이다. 그런데 judge는 온도 1에서 동일판정률이 ~70%로 떨어지고 체계적 편향·약한 교정을 보인다("Reliability without Validity", arXiv 2606.19544). 즉 **측정 도구 자체가 미검증**이며, Mem0 vs Zep의 공개 채점 분쟁이 이를 방증한다.

**오염 문제.** 정적 메모리 벤치는 학습 데이터로 유출된다(인기 벤치 오염률 최대 ~90% 보고). 오염 저항 프로토콜이 없다.

**공백.** 선행연구 조사 결과 — 개별 조각은 이미 혼잡하다: 망각 지표(FAMA), 모순 분류(MemConflict), 결정론적 supersession(MemStrata), 연산 어휘(GEM), 선택적 망각 과업(MemoryAgentBench). 그러나 **① 절차생성 ② 유효기간 명시 ③ 연산수준 분리 채점 ④ 완전 judge-free**를 **모두 결합**한 스위트는 미존재. 특히 MemStrata는 judge-free이나 자기 방법 검증용으로 협소하고, MemoryAgentBench는 망각을 다루나 **LLM judge로 채점**한다.

## 3. 연구 질문 & 설계 목표

- **RQ1** 회수 점수가 높은 메모리 시스템이 실제 생애주기 연산(폐기·병합·만료·해소)에서도 우수한가, 아니면 **회수가 연산 능력을 가리는가**?
- **RQ2** LLM-judge 점수와 **계산가능 정답** 간 괴리는 얼마이며, 어떤 연산에서 가장 큰가?
- **RQ3** 시간 지평(주→분기)이 길어질수록 연산 실패가 어떻게 증가하는가(FAMA 관측의 연산수준 재현)?

**설계 목표:** (a) 절차적·파라미터화 생성으로 오염 저항, (b) 모든 정답이 LLM 호출 없이 결정론적으로 계산, (c) 연산별 분리 지표 + 통합 FAMA 페널티, (d) 인간일치 교정 슬라이스로 judge-free 지표의 타당성 입증.

## 4. 제안 방법

### 4.1 절차적 히스토리 생성기
- **엔티티-속성 상태기계**: 각 엔티티가 시간에 따라 속성값을 바꾸는 궤적을 난수 파라미터(변경률·모순주입률·중복률·시간지평)로 생성. 각 (엔티티, 속성, 값)에 **valid_from/valid_to**를 부여.
- **세션 스크립트화**: 상태 변경을 자연어 다세션 대화/문서로 렌더(분포 다양성 위해 템플릿+패러프레이즈). 방해요소(distractor)로 **superseded 값**과 무관 사실 주입.
- **파라미터 노출**: 변경률·모순밀도·중복률·시간지평을 축으로 리포트(오염 시 재생성만 하면 됨).

### 4.2 연산수준 과업 & 결정론적 검증기 (judge-free)
| 연산 | 질의 형태 | 정답 계산(LLM 무호출) |
|---|---|---|
| **Write/회수** | "X의 현재 값은?" | 상태기계의 as-of 값과 정확일치 |
| **Forgetting/expiry** | "미확인 Y를 아직 신뢰하나?" | 재확인 로그로 만료 여부 계산; 만료본 사용 시 감점 |
| **Contradiction** | "Z에 대해 상충 정보가 있나? 무엇이 최신?" | supersede 그래프의 최신 유효값 |
| **Merge/dedup** | 저장 상태 검사 | 중복 엔트리 수·병합 정확도(상태 비교) |
| **Temporal-validity** | "2026-04 시점 X는?" | as-of 질의 정확일치 |

모든 정답이 생성기 ground truth에서 계산 → **judge 불필요**. 자유서술 응답은 정규화 추출 후 정확일치/집합일치로 채점.

### 4.3 지표
- 연산별 정확도(위 표), **FAMA = max(0, MPA − λ·(1−FAA))** 병행 보고, staleness 사용률, 시간지평별 열화 곡선.
- **타당성 슬라이스**: 부분집합에 인간 주석 + 대표 LLM-judge를 동시 적용해 judge-vs-계산정답 일치도를 신뢰구간과 함께 보고(자매 제안 T2의 씨앗).

## 6. 예상 기여

1. **두 시간축의 exact state와 operation trace를 함께 채점하는 벤치마크 후보** — ForgetEval·Mem2ActBench와 동일 조건에서 차이를 검증한다.
2. **오염 저항** — 파라미터 재생성으로 리더보드 수명 연장.
3. **judge 타당성 증거** — judge-vs-계산정답 괴리를 정량화, 기존 메모리 점수의 신뢰도에 경종.
4. **후속 연구 인프라** — T11(믿음개정)·T7(컴팩션)·T5(충돌검색)의 공통 측정 기반.
